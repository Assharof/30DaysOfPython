#  Day 7 - Sets

##  Topics Covered

* Set creation and properties
* Adding and removing elements
* Set operations (union, intersection, difference)
* Removing duplicates using sets
* Real-world use of sets

##  What I Learned

* Sets store only **unique values**
* Sets are **unordered**
* Useful for removing duplicates from lists
* Powerful operations like union and intersection
* Difference between `remove()` and `discard()`

##  Exercises Completed

###  Set Basics

* Found length of a set
* Added and updated items
* Removed elements from a set

###  Set Operations

* Union of sets
* Intersection of sets
* Subset and disjoint checks
* Symmetric difference

###  Real-World Use

* Converted list to set to remove duplicates
* Counted unique words in a sentence

##  Sample Highlight

```python
age = [22, 19, 24, 25, 26, 24, 25, 24]
print(set(age))  # removes duplicates
```

##  Key Differences

| Type   | Ordered | Mutable | Unique |
| ------ | ------- | ------- | ------ |
| String | ✅       | ❌       | ❌      |
| List   | ✅       | ✅       | ❌      |
| Tuple  | ✅       | ❌       | ❌      |
| Set    | ❌       | ✅       | ✅      |
